Matrix26 Appearance Studio — Phase 3C.6

This phase integrates Appearance Studio with new-instance provisioning.

A new portal can now be created with:
- theme;
- public layout;
- administrative layout;
- login layout;
- color overrides;
- branding texts;
- optional bundled visual assets.

The visual identity is installed as local version v1 during provisioning and is
registered immediately in Matrix26 Appearance Studio.

Recommended test data:
  sample-data/matrix26-provisioning-appearance-demo/test-data.txt

No manual SQL is required.
