Cómo usar Cartera de clientes

Esta página ayuda a decidir a qué clientes cuidar, cobrar, reactivar o priorizar según ingresos, margen, fiado y frecuencia de compra.
1. Mira los top clientes

Los rankings por ingreso y ganancia muestran cuentas importantes que conviene fidelizar.

2. Controla fiado

El fiado pendiente ayuda a priorizar cobranza antes de seguir vendiendo sin control.

3. Reactiva clientes

Los clientes fuera de ciclo o dormidos son oportunidades para WhatsApp, llamadas o promociones.

4. Lee la salud

El ranking general combina ventas, margen, frecuencia y deuda para orientar acciones comerciales.

Qué hacer si no aparecen clientes

  • Registra pedidos dentro del período analizado.
  • Verifica que los clientes estén activos.
  • Amplía el rango a 60 o 90 días.
  • Registra pagos o cuentas por cobrar para ver riesgo de fiado.
  • Usa la ficha del cliente para revisar su historial.
