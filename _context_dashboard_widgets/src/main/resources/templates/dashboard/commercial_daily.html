Cómo usar el Panel comercial diario

Esta página sirve como tablero operativo para vender más cada día. Reúne ventas, recompra, clientes fríos, campañas y entregas que pueden afectar la venta.
1. Revisa el período

Usa 7, 30 o 90 días para cambiar la lectura comercial. El día actual siempre ayuda a priorizar el trabajo inmediato.

2. Contacta prioridades

Empieza por clientes con probabilidad de recompra, clientes fuera de ciclo o clientes con fiado que necesitan seguimiento.

3. Usa campañas activas

Las promociones y contenidos sirven como argumento para WhatsApp, llamadas o publicaciones del día.

4. Cruza con operación

Si hay pedidos por entregar o incidencias, atiéndelos antes de empujar nuevas ventas al mismo cliente.

Qué hacer si no aparece información

  • Registra ventas desde Nuevo pedido.
  • Mantén clientes activos con teléfono y perfil.
  • Registra promociones vigentes si quieres ver campañas.
  • Registra entregas y estados para ver incidencias operativas.
  • Amplía el rango de fechas si el período actual tiene poca actividad.
