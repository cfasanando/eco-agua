1. Selecciona una idea del banco.

3. Cambia el estado a listo o publicado cuando avance el trabajo.

Cuidado importante
Evita publicar información no validada.
Antes de marcar una publicación como lista, confirma stock, presentación, precio y zona de entrega. El plan mensual organiza el trabajo, pero no reemplaza la validación operativa.

Ayuda - Plan mensual de publicaciones

Esta pantalla sirve para ordenar el contenido que sí se trabajará durante el mes. No es solo una lista de ideas: aquí se define fecha, canal, tema, responsable y avance.

Campo Uso recomendado
Fecha de publicación Día tentativo en que se debe publicar o preparar la pieza.
Idea relacionada Permite conectar la publicación con el banco de ideas para no duplicar trabajo.
Campaña Útil para temporadas como San Juan, Fiestas Patrias o promociones puntuales.
Texto base Borrador que luego se ajusta según formato, stock y canal.
Estado Permite controlar si la publicación está pendiente, en preparación, lista, publicada o cancelada.
No marques como lista una publicación que mencione stock, precio o entrega sin confirmarlo primero. Esto evita reclamos y mantiene la confianza del cliente.
