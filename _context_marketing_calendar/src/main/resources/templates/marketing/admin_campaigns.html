Cómo usar el Panel de campañas marketing

Esta página agrupa promociones, contenido, testimonios y mensajes comerciales para saber qué puedes mover hoy en redes, WhatsApp o atención al cliente.
1. Revisa promociones

Identifica ofertas activas o por vencer para priorizar publicaciones y mensajes de venta.

2. Usa contenido

Los posts publicados y drafts sirven para educar al cliente y sostener presencia digital.

3. Refuerza confianza

Los testimonios ayudan a reducir dudas antes de cerrar una venta.

4. Aplica CTAs

Usa las plantillas de WhatsApp como base para primera compra, recompra o reactivación.

Qué hacer si la página se ve vacía

  • Crea promociones activas desde el módulo Promociones.
  • Publica o prepara posts desde el módulo Blog.
  • Registra testimonios activos para reforzar confianza.
  • Revisa que las fechas de inicio y fin de promociones estén vigentes.
  • Usa el Panel comercial para convertir campañas en acciones de venta.
