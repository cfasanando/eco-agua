Criterio del cálculo
  • El CVU sale de la composición real del producto en product_supply.
  • Las ventas comparables incluyen solo pedidos PAID y CREDIT.
  • Los costos fijos excluyen conceptos variables por botellón ya cargados dentro del CVU.
  • Como este producto se vende por perfil de cliente, el punto de equilibrio debe leerse por escenario de precio.
  • Este producto sigue usando su precio principal actual como referencia base.
Lectura recomendada: si el negocio vende el mismo botellón a precios distintos según perfil, no uses un solo precio fijo para decidir metas. Mira primero la tabla de escenarios y luego compara cuánto vendiste realmente en cada uno.
Guía rápida

Cómo usar Punto de equilibrio

Esta página calcula cuántas unidades necesitas vender para cubrir los costos fijos del mes usando el costo variable directo y el precio de venta.
1. Selecciona producto

El producto define el precio, composición de insumos y costo variable unitario.

2. Elige el mes

El mes define qué ventas y costos fijos se usan para comparar el avance real.

3. Lee el PE

El punto de equilibrio indica la cantidad mínima de unidades para cubrir la estructura del período.

4. Compara escenarios

Si hay precios por perfil, revisa cada escenario antes de decidir metas comerciales.

Qué revisar si el cálculo no parece correcto

  • Verifica que el producto tenga precio y composición de insumos.
  • Genera o registra costos fijos para el mes seleccionado.
  • Revisa que existan ventas cerradas como PAID o CREDIT.
  • Confirma que el producto seleccionado sea el correcto.
  • Compara escenarios si el precio cambia por perfil de cliente.
