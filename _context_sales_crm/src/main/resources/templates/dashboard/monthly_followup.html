Cómo usar Seguimiento del mes

Esta página ayuda a saber si el mes va en buen ritmo. Compara lo que ya se vendió contra el punto de equilibrio necesario para cubrir costos fijos y operación real.
1. Elige producto y mes

El producto seleccionado define las unidades, precio promedio y margen. El mes define ventas acumuladas, días restantes y base fija.

2. Mira el PE del mes

El PE indica cuántos botellones se necesitan vender para cubrir la estructura del mes. Si vendiste menos, todavía falta cubrir costos.

3. Revisa el ritmo

La meta diaria restante muestra cuánto necesitas vender por día desde hoy hasta fin de mes para alcanzar el objetivo.

4. Ajusta datos base

Si los números no parecen reales, revisa costos fijos, gastos operativos, precios, pedidos registrados y producto seleccionado.

Qué hacer si la pantalla aparece vacía o en cero

  • Verifica que existan productos activos.
  • Registra ventas del producto en el mes seleccionado.
  • Registra costos fijos del mes.
  • Registra gastos operativos para mejorar la lectura real.
  • Confirma que el año y mes del filtro sean correctos.
