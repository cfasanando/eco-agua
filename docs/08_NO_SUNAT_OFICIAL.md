# Alcance contable V1: no vender como SUNAT oficial

## Mensaje correcto

La V1 puede presentarse como:

```text
Sistema integral de gestión interna con reportes financieros y contabilidad interna de apoyo para revisión contable.
```

## Mensaje incorrecto

No vender todavía como:

```text
Sistema SUNAT oficial.
Sistema PLE/SIRE.
Sistema de libros electrónicos oficiales.
Sistema contable certificado.
```

## Por qué

Los módulos actuales ayudan a ordenar:

- ingresos;
- egresos;
- cuentas por cobrar;
- cuentas por pagar;
- caja;
- asientos internos;
- libro diario interno;
- mayor;
- balance de comprobación;
- estado de resultados;
- balance general interno.

Pero todavía falta validar con un contador:

- régimen tributario;
- IGV real aplicable;
- comprobantes oficiales;
- registro de ventas oficial;
- registro de compras oficial;
- SIRE;
- PLE;
- libros electrónicos;
- formatos de exportación oficiales.

## Recomendación

Para V1, usar la contabilidad como control interno y apoyo para contador.

SUNAT oficial debe ser una fase posterior independiente.
