# Backlog recomendado después de V1

## Prioridad alta

1. Pruebas reales con Agua Eco durante varios días.
2. Pruebas reales con Productos de la Selva Belén.
3. Corrección de errores detectados en operación.
4. Backups automáticos por base de datos.
5. Limpieza de claves externas en archivos de configuración.
6. Mejorar rendimiento de dashboard si crecen los datos.

## Prioridad media

1. Roles y permisos por acción.
2. Auditoría de cambios críticos.
3. Exportables Excel/PDF de reportes principales.
4. Flujo de compra formal desde requerimientos.
5. Control más completo de proveedores.
6. Trazabilidad de lote hacia ventas.
7. Alertas automáticas por WhatsApp o correo.

## Prioridad baja

1. UI más compacta para móviles.
2. API externa.
3. Multi-tenant SaaS real.
4. Integración con pagos digitales.
5. Integración SUNAT oficial.

## No hacer hasta tener datos reales

- Más dashboards avanzados.
- Más reportes contables oficiales.
- Reescritura global del sistema.
- Migración a arquitectura SaaS multi-tenant.
