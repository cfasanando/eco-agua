# Matrix26 Branding Demo Kit

Este kit permite probar **Appearance Studio 3C.5** sin buscar imágenes externas.

## Uso más rápido

En Matrix26:

1. Abre la instancia `Matrix26 Restaurant Laboratory`.
2. Entra a **Apariencia → Branding y recursos**.
3. Pulsa **Cargar kit demo completo**.
4. Regresa al detalle de apariencia y publica la nueva versión.
