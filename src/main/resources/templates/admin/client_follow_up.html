Cómo usar Seguimiento de clientes

Esta pantalla no crea un CRM separado. Usa pedidos reales para priorizar contactos, cobranza, reactivación y fidelización.
1. Cobra primero

Si el cliente tiene fiado pendiente, prioriza coordinación de pago antes de ofrecer más crédito.

2. Reactiva a tiempo

Los clientes fuera de ciclo pueden recuperarse con un mensaje directo por WhatsApp o una oferta puntual.

3. Usa el canal principal

El canal más usado ayuda a decidir si conviene escribir por WhatsApp, redes o atender de forma presencial.

4. Fideliza clientes buenos

Los clientes con buen movimiento no solo se cobran: también se cuidan, se fidelizan y pueden traer referidos.

Qué hacer si no aparecen clientes

  • Amplía el rango a 60 o 90 días.
  • Registra pedidos reales para que el sistema calcule frecuencia.
  • Completa teléfonos para activar el botón de WhatsApp.
  • Revisa la cartera completa si quieres ver clientes sin prioridad urgente.
