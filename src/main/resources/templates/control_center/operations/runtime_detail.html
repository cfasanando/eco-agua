Stop runtime

Matrix26 will request a graceful shutdown and wait for port 8094 to become free.

If graceful shutdown times out, Matrix26 records the failure first. A separate force-stop action becomes available only after ownership is verified.
STOP code

Restart runtime

Matrix26 will stop the current process, verify that the port is free, start a replacement process, and wait for the HTTP health check.

RESTART code

Force stop verified runtime

Use this only after graceful shutdown timed out. Matrix26 will verify the Java process, runtime profile, configuration path, and port before requesting a forced termination.
FORCE STOP code

Adopt verified process

The process is already running and matches the registered profile, configuration, and port. Adoption records its PID without restarting or terminating it.

ADOPT code

Clean stale PID metadata

Only the stale runtime.pid file will be removed. No process, database, configuration, asset, or log will be deleted.

CLEAN PID code

Rotate runtime logs

Current runtime logs will be compressed as numbered GZIP archives. The runtime must remain stopped while the files are rotated.

ROTATE LOGS code
