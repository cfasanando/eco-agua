Ayuda: Biblioteca de imágenes

Esta herramienta sirve para no perder fotos, banners o portadas entre carpetas sueltas. Cada imagen queda registrada con una clasificación y una relación opcional.

  • Foto de producto: úsala para catálogo, productos destacados o publicaciones.
  • Banner: úsalo para campañas del portal, promociones o fechas especiales.
  • Portada de blog: recurso pensado para artículos o consejos.
  • Imagen para redes: pieza lista o referencial para Facebook, TikTok o WhatsApp.
  • Archivado: oculta recursos antiguos sin borrar el historial.
Esta fase solo ordena y almacena imágenes. No edita imágenes, no genera diseños automáticamente y no cambia productos, precios ni promociones.
